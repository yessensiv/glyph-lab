# GLYPH LAB

New landing page and browser-local image conversion studio for developers and visual makers.
The supplied reference defines the interface language; its identity, words, and artworks are not reused.

Design read: terminal editorial; variance 5, motion 1, density 5, assets 7, brand fidelity 3.
Hero introduces the transformation; the studio makes it immediately usable; later sections teach export choices.
Laptop and phone viewing, quiet and precise; wide hero becomes a single column on phones.

One monospace stack: JetBrains Mono, IBM Plex Mono, ui-monospace, Menlo, monospace.
Background #0A0A0B, surfaces #141417, foreground #EDEDEF, muted #8B8B93, accent #B7A9F8.
8px spacing basis, 8px corners, 1px rgba(255,255,255,.09) borders; no shadows, glow, or UI gradients.
No entry animation. Immediate preview adjustments and short hover feedback only.

Assets: dist/assets/shell.webp, terrain.webp, arch.webp, orbit.webp — original procedural sculptural studies.
All displayed ASCII previews are converted from these sources using the actual tool engine.
Brand glyph is typographic [ : : ], with a stacked GLYPH / LAB wordmark.
English and Russian interface. Source is available as a local MIT-licensed download.
